# Home Components

This directory contains distinct sections of the landing page.

## Components

### `Hero`

The main entry point of the homepage.

- Displays the primary value proposition ("Custom Apparel Manufacturing").
- Includes "View Catalog" call-to-action.

### `FeaturedProducts`

A showcase section for popular or new items.

- **Features**:
  - Horizontal scrollable list (or grid) of product cards.
  - "AI Search" input field that glows when focused.

### `HowItsDone`

An informational section explaining the manufacturing process.

- **Content**: Visual breakdown of steps (e.g., Design, Prototype, Production).

### `FeaturedContent`

Secondary content blocks or marketing highlights featuring:

- Brand values.
- Additional services or categories.
